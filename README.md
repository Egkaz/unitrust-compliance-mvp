🛡️ UniTrust: AI-Powered University Compliance Platform
UniTrust — это интеллектуальная цифровая экосистема, созданная для управления университетскими политиками и анонимной отчетности об инцидентах. Проект решает проблему «университетского феодализма» и культуры молчания, предоставляя студентам безопасный инструмент для защиты своих прав.

🚀 Основные возможности
Интеллектуальная анонимность (Zero-Knowledge): Встроенная нейросеть Gemini анализирует сообщения и автоматически удаляет персональные данные (ФИО, контакты) до того, как они попадут в базу данных.

Автоматический триаж и скоринг: Система мгновенно классифицирует инцидент и определяет его уровень критичности (Критический, Высокий, Стандартный).

Центр политик: Единая база знаний всех регламентов университета с мгновенным поиском по категориям.

Compliance Dashboard: Визуализация «здоровья» вуза в реальном времени. Общий рейтинг безопасности (сейчас: 98.2%) и статус системы позволяют администрации быстро выявлять проблемные зоны.

🛠 Технологический стек
AI Engine: Google Gemini 1.5 Flash (для деперсонализации и анализа рисков).

Backend & DB: Firebase (Security Rules гарантируют, что доступ к отчетам имеют только авторизованные комплаенс-офицеры).

Frontend: Реактивный интерфейс с поддержкой ролей (Аноним, Студент, Администратор).

🧩 Структура проекта
/src: Исходный код платформы.

server.ts: Логика интеграции с Gemini API.

firestore.rules: Правила безопасности, ограничивающие доступ к конфиденциальным данным.

security_spec.md: Описание протокола анонимизации данных.

⚙️ Установка и запуск
Клонируйте репозиторий.

Установите зависимости: npm install.

Создайте файл .env и добавьте ваш GEMINI_API_KEY.

Запустите приложение: npm run dev.
